# Nexus — mises à jour

**Télécharger le launcher :** [Nexus.exe](https://github.com/Mpixel44/client-launcher/raw/mises-a-jour/Nexus.exe)
— c'est tout ce qu'il faut : au premier lancement il demande où installer le jeu, puis télécharge les packs et les mods.

Le reste de cette branche est généré automatiquement : `manifest.json` (signé par `manifest.sig`)
et les fichiers nommés par leur empreinte SHA-256. Ne pas modifier à la main.
(`Launcher.exe` est une copie de `Nexus.exe` pour les anciens liens.)
