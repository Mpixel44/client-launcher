# Mises à jour du launcher

**Télécharger le launcher :** [Launcher.exe](https://github.com/Mpixel44/client-launcher/raw/mises-a-jour/Launcher.exe)
— c'est tout ce qu'il faut : au premier lancement il télécharge les packs et les mods.

Le reste de cette branche est généré automatiquement : `manifest.json` (signé par `manifest.sig`)
et les fichiers nommés par leur empreinte SHA-256. Ne pas modifier à la main.
